# Дуотригордль

Русскоязычный клон Duotrigordle: 32 слова из 5 букв отгадываются одновременно, максимум 37 попыток.

## Запуск

```bash
npm install
npm run dev
```

## Игра по сиду

Введите число или любую строку в поле «Сид» и нажмите «Новая игра» — набор из 32 слов будет
детерминированно сгенерирован из этого сида (`src/game/duotrigordle.ts`). Это основа для будущей
ежедневной раздачи (daily seed).

## Словарь

`src/data/words.txt` — 26 471 русских слов из 5 букв (источник:
[mediahope/Wordle-Russian-Dictionary](https://github.com/mediahope/Wordle-Russian-Dictionary)),
используется и как словарь допустимых слов, и как пул ответов.
